# 🚀 Desafio Flexbox - Cards de Postagens Horizontais

Este projeto foi desenvolvido como resolução de um desafio prático de **CSS Flexbox**, focado na reestruturação do layout de postagens.

## 🎯 Objetivos do Desafio

1. **Alteração do Eixo do `article`:** Alterar `flex-direction` para exibir o conteúdo (imagem, título e texto) em linha (`row`).
2. **Largura Total:** Ajustar a propriedade `flex` para que cada card ocupe **100% da largura** disponível.
3. **Alinhamento Customizado (`align-self`):** Aplicar a propriedade `align-self` em um elemento interno (botão) para alterar o alinhamento individual em relação ao contêiner.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3 (Flexbox)**
- **JavaScript (ES6)**
